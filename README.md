# Demo PHP website for Scotiabank developer job application
Requirements to Run This PHP Website Locally

1- Local Server: Install a server environment like:

- XAMPP
- WAMP
- MAMP
- LAMP

These include Apache/Nginx, PHP, and MySQL/MariaDB.

2- PHP: Ensure PHP is installed and matches the required version. Check with:

```
php -v
```

3- Database (if required): Use MySQL/MariaDB or other DBMS for database-driven projects. Tools like phpMyAdmin can simplify database management.

4- Project Directory: Place your project in the server's default directory:

XAMPP: htdocs (C:\xampp\htdocs)
WAMP: www (C:\wamp\www)
Access it via http://localhost/<project_name>.

5- Composer (if needed): If your project depends on modern PHP libraries, install Composer:

```
php -r "copy('https://getcomposer.org/installer', 'composer-setup.php');"
php composer-setup.php
php -r "unlink('composer-setup.php');"
```

6- Browser: Open the site in any modern web browser (e.g., Chrome, Firefox).
